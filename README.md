# Genius.it

Genius.it è una piattaforma per il matching di clienti e professionisti. La piattaforma consente di:
- Registrare utenti come clienti o professionisti.
- Creare richieste di preventivo (RDP).
- Abbinare clienti con professionisti in base a categoria, città e competenze.
- Gestire notifiche, chat e pagamenti.

## Struttura del Progetto
- **Backend**:
  - Implementato con Node.js e Express.
  - Database MongoDB per la gestione dei dati.
- **Frontend**:
  - Interfaccia utente sviluppata con React.js.
  - Comunicazione con il backend tramite API REST.
